## Idiomas soportados

**Español** (default y fallback), **inglés** y **portugués**. El idioma elegido se
persiste en `localStorage` bajo la clave `echochat-lang` y se refleja en el atributo
`lang` del `<html>`.

## Archivos de locale

Un archivo JSON plano por idioma en `frontend/src/locales/`: `es.json`, `en.json`,
`pt.json`. Namespaces de dominio anidados dentro del mismo archivo — no hay archivos
separados por namespace:

```
common, confirm, logout, auth, chat, newConversation, channels, saved,
poll, code, contacts, notifications, settings, broadcasts, admin,
monitoring, sidebar, layout, commandPalette, imageViewer, wallpaper, call
```

## useTranslation en componentes

```javascript
import { useTranslation } from 'react-i18next';

function LoginPage() {
  const { t } = useTranslation();
  return <Button>{t('auth.login')}</Button>;
}
```

**Nunca hardcodear texto visible al usuario en JSX** — es una regla obligatoria del
proyecto (ver `AGENTS.md`).

## Agregar nuevas cadenas

1. Agregá la clave en `es.json` (idioma de referencia).
2. Agregá la misma clave con su traducción en `en.json` y `pt.json` — las tres deben
   quedar sincronizadas en la misma entrega.
3. Usá `t('namespace.clave')` en el componente.

## Convenciones de claves

Claves anidadas por namespace de dominio, en `camelCase`, reflejando la jerarquía de la
UI: por ejemplo `auth.loginTitle`, `settings.notifications.quietHours`,
`monitoring.sections`.

## Pluralización

`i18next` soporta pluralización nativa por sufijo de clave (`_one`/`_other` en inglés y
portugués, reglas propias en español) cuando el mensaje depende de una cantidad — usarla
en lugar de armar el string a mano con concatenación.

## Fechas y formatos

Las fechas y horas se formatean acorde al locale activo en los componentes que las
muestran (por ejemplo, timestamps de mensajes, historial de llamadas). No hardcodear
formatos fijos como `DD/MM/YYYY` fuera del contexto de un locale.

## Documentación del sitio

Este sitio de documentación (el que estás leyendo) es **solo en español** — a diferencia
de la aplicación EchoChat, no tiene selector de idioma ni versiones en inglés/portugués.
